## How to use these lessons

1. **Draw before reading the answer.** A rough request path is enough to expose a gap in your understanding.
2. **Write down assumptions.** Keep units next to estimates and separate requirements from guesses.
3. **Explain one choice out loud.** State what it improves, what it costs and when you would change it.
4. **Try a failure case.** Ask what happens when a database is slow, a request is retried or a dependency disappears.

!!! note "A starting point, not an interview guarantee"
    These introductory lessons are original BuildMyX learning material. Interview formats and expectations vary by role and company. Use the exercises to build reasoning, then practise with the requirements for your target role.
