# Topic coverage and further reading

This course uses the supplied [Aman.ai Python primer](https://aman.ai/primers/python/) as a **topic inventory**. The explanations and worked examples are original BuildMyX material, organized into fifteen chapters for Python 3.12+. Older features are retained as clearly labelled historical topics rather than presented as current Python behavior.

The inventory captured on **13 November 2026** contains **160 section/subsection headings**: 157 teaching headings and three bibliography/attribution headings. Each row below links the reference section to the relevant part of this course. File-method, magic-method and exception tables are included as well; they are not omitted simply because their individual entries were not headings.

## Sources and further reading {#sources}

- **Coverage reference and attribution:** [Aman.ai — Python primer](https://aman.ai/primers/python/), referenced for its topic list on 13 November 2026. Follow that link for the original article and its citation information.
- **Language tutorial:** [The official Python tutorial](https://docs.python.org/3/tutorial/) is the next reference for syntax and standard features.
- **Style:** [PEP 8](https://peps.python.org/pep-0008/) and [PEP 257](https://peps.python.org/pep-0257/) cover code and docstring conventions; [PEP 20](https://peps.python.org/pep-0020/) records the Zen of Python.
- **Types:** [Standard types](https://docs.python.org/3/library/stdtypes.html), [typing](https://docs.python.org/3/library/typing.html) and [the typing specification](https://typing.python.org/en/latest/spec/) provide precise API and annotation details.
- **Objects:** [The data model](https://docs.python.org/3/reference/datamodel.html) and [dataclasses](https://docs.python.org/3/library/dataclasses.html) explain the protocols behind classes.
- **Files and failures:** [Input/output](https://docs.python.org/3/tutorial/inputoutput.html), [io](https://docs.python.org/3/library/io.html) and [built-in exceptions](https://docs.python.org/3/library/exceptions.html) document stream behavior and error families.
- **Practice environments:** [Jupyter documentation](https://docs.jupyter.org/en/latest/) and [Colab](https://colab.research.google.com/) explain notebook workflows.

For attribution when sharing this course, link to **BuildMyX Learn: Python** and the chapter you used. When citing the reference primer itself, use the original site's citation details rather than attributing its article to BuildMyX.
