## How to work through a chapter

1. **Predict the result.** Ask which object changes, which value is returned or which exception should occur.
2. **Run the Python blocks in order.** Examples within a chapter build on earlier blocks. Use one script or a notebook with a fresh kernel. Chapter 14 also labels separate files to create before importing them.
3. **Check the assertions.** `assert` is used here to make expected results explicit. It is not a replacement for production input validation.
4. **Change one thing.** Try empty data, a missing value or an unexpected type. Explain the result before moving on.
5. **Try the exercise.** Compare your reasoning with the expandable self-check answer.

Examples use the standard library and target Python 3.12+. They are displayed for you to run locally; this website does not execute uploaded code or collect exercise answers.
